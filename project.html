How to Deploy & Publish This Website

Follow these simple step-by-step instructions to take this page live on the internet for free.

1

Save your Code in VS Code

Ensure this whole code block is saved inside a file named index.html inside your local project folder.

2

Option A: Deploy via GitHub Pages (Recommended)

  • Create a free account on GitHub.com.
  • Create a new public repository (e.g., student-attendance-analysis).
  • Upload your index.html file.
  • Go to Settings > Pages, select main branch, and hit Save.
  • Your website will be live in 1 minute at https://username.github.io/repository-name.
3

Option B: Deploy via Netlify Drop (Instant)

Go to app.netlify.com/drop, drag and drop the folder containing your index.html file, and get an instant live URL instantly!
